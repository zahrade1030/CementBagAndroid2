# شمارشگر کیسه – پروژه اندروید

این پروژه یک اسکلت اجرایی Kotlin برای اندروید است که از CameraX برای دوربین زنده و ONNX Runtime برای اجرای مدل `best.onnx` به‌صورت آفلاین استفاده می‌کند.

## قابلیت‌های پیاده‌سازی‌شده
- پیش‌نمایش دوربین پشت
- اجرای مدل ONNX روی فریم دوربین
- رسم کادر تشخیص
- دو خط قابل جابه‌جایی در حالت «تنظیم خطوط»
- قفل خطوط در حالت «شروع شمارش»
- توقف و ریست شمارش
- گردش کار GitHub Actions برای ساخت APK

## مدل
فایل `best.onnx` از پروژه اصلی در `app/src/main/assets/best.onnx` قرار داده شده است.
مدل در این نسخه با فرض ورودی RGB با اندازه 640×640 و خروجی YOLO تک‌کلاسه `[1,5,N]` یا `[1,N,5]` خوانده می‌شود. اگر مدل شما خروجی دیگری داشته باشد، بخش decode در `YoloDetector.kt` باید مطابق شکل واقعی خروجی تنظیم شود.

## منطق شمارش
منطق دو خطی مشابه اسکریپت پایتون است: جسم ابتدا باید وارد ناحیه بین دو خط شود و سپس از خط بالایی به سمت بالا عبور کند تا یک بار شمرده شود.
ردیابی این نسخه یک ردیاب سبک مرکز-به-مرکز است و **ByteTrack اصلی Ultralytics نیست**؛ برای برابری کامل با نسخه پایتون باید مرحله ردیابی با خروجی/رفتار ByteTrack تطبیق داده و روی ویدیوهای واقعی آزموده شود.

## ساخت APK بدون Android Studio
1. این پوشه را در یک مخزن GitHub بارگذاری کن.
2. از تب Actions، گردش کار `Build Android APK` را اجرا کن.
3. فایل `CementBagCounter-debug-apk` را از بخش Artifacts دانلود کن.
4. APK داخل فایل ZIP قرار دارد.

## نکته مهم
این نسخه پروژه اولیه قابل ساخت است، نه APK تأییدشده روی گوشی. قبل از استفاده واقعی باید شکل ورودی/خروجی مدل، چرخش/نسبت تصویر دوربین، سرعت inference و دقت شمارش با فایل‌های ویدیویی اصلی آزمایش شود.
